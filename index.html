Setup Instructions (Free Firebase Database):

  1. Go to console.firebase.google.com and click Add Project (name it e.g. MyCureCraft).
  2. In the left menu, select Build > Firestore Database, click Create database, select Start in test mode, and pick a location.
  3. In the left menu, select Build > Authentication, click Get started, go to Sign-in method, enable Anonymous, and click Save.
  4. Click the gear icon ⚙️ (Project Settings) at the top left, scroll to Your apps, click the web icon (</>), and register the app.
  5. Copy the generated firebaseConfig keys and paste them into the input fields below!
